# Samples

`TKB_THCS_sample.xlsx` is the school's 2026–2027 secondary timetable workbook with every person made up: names, short names, emails, phones, the comment author, and the file's author. The school's name, logo, and links are gone too. The sheets, formulas, merged cells, layout, classes, subjects, and the timetable itself are the real workbook's, so it imports into the app like the real one.

Each made-up teacher keeps one name, short name, email, and phone everywhere they appear, so the joins between sheets still work. The real workbook isn't in the repository and must never be added.
