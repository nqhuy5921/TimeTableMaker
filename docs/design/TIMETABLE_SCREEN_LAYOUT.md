# Timetable Screen — Layout Spec

Reference design: `TTM Timetable v4.dc.html` (screen 5a on `TimeTableMaker Mockups.dc.html`). Target viewport 1440 × 900; everything fits without page scroll. No screen ever scrolls as a whole, at any window size from 1280 × 720: the side panel, the grid, and the Cards table each scroll inside their own frame, so a page scrollbar can't push the layout left (2026-10-21, at the user's request).

## Theme
- Header colour (app header + timetable header, always the same): `#6a3cbf`
- Font: Lexend, weights 300 (body) / 400 (emphasis). Must support Vietnamese.
- Neutrals: ink `#0d253d`, secondary `#273951`, muted `#64748d`, borders `#c9d3de` / `#dde3ea` / `#e3e8ee`, subtle fill `#f6f9fc`
- Accent: `#533afd` (selection, hover, active tab). Error `#ea2261`.

- Save notice (added 2026-10-21 at the user's request, in place of a red strip above the screen): when a save fails, a notice drops down from under the header, centred, 600px wide at most, over whichever screen is open, so nothing on the page moves. `--danger-bg` fill with a 4px `--danger` left edge, `--radius-md`, `--shadow-2`, 13px text. Hide puts the notice away until the next failed save, since it covers part of the class bar (added at the R1-10 review, 2026-10-21). It slides down 8px over 180ms (none with reduced motion) and goes away once a save works. Its top is `--header-height` (56px) plus 12px.
- Menu: one link per screen (Timetable, Cards, Teachers, Classes, Rooms, Subjects); the active one is a white pill with its label at weight 400 (the others 300). Every link is as wide as its label at weight 400, so the links never shift when the active one changes (fixed 2026-10-21 at the user's request: the active link's heavier text made it 2–3px wider and pushed the links after it). Version on the right.
- No undo / redo (TB-6 removed on 2026-10-16).
- Profile pill (release 4, approved 2026-10-28; SYSTEM_DESIGN §11.5): after the brand, the open profile's name in a pill (white at 15% over the header color, white 13px text at weight 400, a white chevron, `8px 16px` padding, at most 200px wide with an ellipsis and the whole name as its tooltip). - Export notice (release 4, approved 2026-10-28): after an export, a notice drops under the header in the save notice's place and frame, white with a 4px `--primary` left edge: "Saved TKB 6A1.xlsx" (15px `--ink`), the folder in muted 13px, and Show in folder and Hide pills on the right. ## Side panel
Two tabs at the top, active tab marked with a 2px accent underline. The Issues tab shows a count badge: the class on screen's errors plus warnings (all classes when none is on screen), pink (`--danger-bg` fill, `--danger` text) with errors, amber (`--warning-bg`, `--warning-ink`) with only warnings, grey at 0 (release 2, approved 2026-10-22). ### Subjects tab
- Search field (accent-insensitive: "toan" matches "Toán").
- Group by: Subject / Teacher.
- The search and grouping stay as they were through a tab switch, a class switch, and a visit to another screen in the header menu (the screen switch added 2026-10-21 at the user's request).
- Cards in a 2-column grid. The panel lists the whole pool of cards for any class on screen, or with none (changed 2026-10-21 at the user's request: cards no longer belong to a class). It has no "No classes yet" or "No class selected" state; an empty pool says "No subjects yet" with Add subject.
  - Grouped by subject: one continuous list in subject order, no group headers (colour identifies the subject).
  - Grouped by teacher: sticky teacher header per group.
- Card = same look as a timetable slot: 84px tall, radius 4px, subject tint background, subject ink text, centred.
  - Line 1: subject name (15px)
  - Line 2: teacher · room (12px)
  - No counts on cards.
- Cards are drag sources. A card can be dropped on the class on screen, whichever class it is on already; with no class on screen the grid has no drop zones (2026-10-21).
