# Fixtures

A made-up sample school for development and tests. Everything here is invented. Never copy names, emails, phone numbers, or other data from `TKB_THCS_from 3.9.2026.xlsx` into this folder.

- `sampleExpectations.ts`: what the tests expect of the made-up sample school (its classes, placed periods, and issues). The school itself moved to `src/domain/exampleSchool.ts` at R5-3, because Download example writes it; it's still made up, and the same rule holds there. It was made for release 1's acceptance pass (R1-8), as a `TimetableFile`. Six classes, one or more in each track (`6A1`, `6A2`, `7AA1`, `8CE1`, `9B1`, `9BA1`), ten subjects including the split-group card "Toán phân hoá/ Ngoại ngữ 2", eight teachers, and six rooms. Cards are one pool for the whole school, not per class: each placement names its class, so the Tiếng Anh card (`k-anh-vy`) is on both 6A1's and 6A2's grids. Cards are placed as full blocks and as halves, two halves share a block in `6A1` and `8CE1`, and `6A1` and `6A2` have the same teacher in the same block, a clash for release 2's checks. Two cards (`k-9b1-toan`, `k-9b1-ly`) are on no grid, and `9B1` and `9BA1` have nothing placed. Every class but `9BA1` has a homeroom teacher, and four teachers have a phone (R4-7), so the export's headers and `Data ` have a full set of details, a few gaps, and a class with none. The comment at the top of the file lists the placed periods per class.
- `reviewSchool.ts`: a bigger made-up school for looking at the screens by eye, opened with `npm run dev:review` (which writes it to `~/.config/TimeTableMaker-review` afresh each run, never the real data folder). 21 classes, 11 of them in grade 6 so the class bar scrolls sideways; 17 subjects, all on 6A1's nearly full grid (46 of 50) so the "Periods per subject" tags wrap; 20 teachers and 45 cards, with Thể dục (Thầy Tùng) on every grade 6 class and several cards on no grid. Every teacher name was checked to be absent from the reference workbook. Since R4-7 every teacher has a full name and most an email and a made-up phone, and every class but 9BA1 has a homeroom teacher (every third an assistant), so an export from it is filled.
- `expectedWorkbook.ts`: the workbook the Excel export (IE-2) should write for the sample school, written out by hand cell by cell (values, formulas with cached results, styles, merges, widths, heights, print setup) from the sample workbook's layout, with no data copied. Since R5-3 it has the `Giáo viên` sheet. `tests/main/exportExcel.test.ts` compares the export with it.
- `referenceWorkbook.ts`: the sample school in the school's workbook layout (`ID GV 1S`, `Data `, `Phan cong`, and `HK1` with `HLOOKUP`s and saved values), as plain read data (`referenceWorkbookData`) and as an ExcelJS workbook (`referenceWorkbook`), with one extra teacher nobody uses and one phone saved as a number. Made from `src/domain/exampleSchool.ts` by code, never from the real workbook. Importing it gives the sample school with no rooms.
